# 开发与运行

## 快速启动

环境：Windows 10/11、JDK 21、Maven。首次构建需要下载 pom.xml 中声明的依赖。

```powershell
mvn test
mvn javafx:run
```

常规测试不连接 SMTP。图形环境下可运行以下命令，短暂打开使用虚拟资料的应用窗口，并生成 `target/ui-smoke/*.png`：

```powershell
mvn test -DuiSmoke=true
```

## 当前实现

- JavaFX 深色导航栏、浅色卡片、青绿色操作按钮；页面支持滚动和可调分栏。
- 读取随包 19 章、173 道习题，章节筛选、选题、文字搜索与完整题目查看；解析段落、代码、图片、原生表格及行内/独立公式资源。
- 资料与邮箱设置，QQ / 163 预设与自动补全邮箱后缀。收件人默认为空。
- 解答、UTF-8 `.java` 导入、多个运行情况、每种情况的多张截图与可选说明、图片和题目排序、UML 导入。
- 读取题库 `uml_required_exercise_ids`，对明确要求 UML 的题目实施必填检查。
- 生成符合课程规则的主题、身份头和正文；编辑预览文字、图片说明、删除内容块与调整图片位置。带公式的混排块与表格暂不提供逐单元格编辑。
- 同一 `PreviewDocument` 输出 WebView 预览、静态 HTML + CID 图片邮件及 Apache POI DOCX。导出使用预览手动修改后的版本。
- 加密草稿的保存/恢复，包括题目、全部图片、运行情况顺序及预览修改；不会引用用户原始图片路径。
- 发送前双重校验、二次确认、后台发送、错误提示与重复点击防护。二次确认使用独立快照；只有用户再次确认后才连接 SMTP。
- 窗口与托盘使用应用图标；右上角关闭默认隐藏到托盘，可在个人中心改为直接退出，托盘「退出」不恢复主窗口，保留草稿保存提示。
- 同一应用目录实行单实例启动；重复双击不创建新窗口。运行时题库按内容版本升级，升级前备份旧题库，保留草稿及设置。

## 操作流程

1. 在「个人中心」填写学院、纯数字班号、学号、姓名、并保存设置。仅预览或导出 DOCX 无需邮箱及 SMTP；提交邮件前需填写教师邮箱、至少一个助教邮箱（最多三个）以及发件账号、SMTP 参数和凭据。
2. 在「选择习题」勾选本章题目。切换章节会提示清空当前题目，可先保存草稿。
3. 在「编辑作业」填写答案；每题可用 Java 源代码区的圆圈加号添加多份代码，用每份代码右侧的圆圈减号删除。粘贴代码后需自行填写名称，无需填写 `.java`，生成正文时自动补全，导入 `.java` 文件会自动填入文件名。每份保留的代码都必须有名称和内容，生成正文时按添加顺序逐份插入名称及源码。旧草稿中的单份源码会保留，需补填名称。添加运行情况并导入截图；按题目要求补充 UML。点击「保存草稿」可命名，留空按系统时间命名；继续编辑后保存会更新原草稿。草稿箱支持打开和确认删除，超出 30 条时自动清理保存时间最早的草稿。
4. 点击「生成正文」，补齐校验提示中的缺失内容。
5. 在预览左侧选择内容块编辑，点击「刷新预览」查看效果。图片可上下移动；完整题目和运行情况的排序建议在原始编辑页调整。
6. 导出 DOCX，或点击「提交邮件」并在列明发件人、收件人、抄送、主题和题数的窗口再次确认。

源数据有改动时，原预览失效，需要重新生成；单纯切换页面、保存或打开草稿不会覆盖已编辑预览。重新生成已有预览前会提示确认。

## 分层与扩展

`domain/model` 不依赖 JavaFX、SQL 或 SMTP；`repository` 定义数据接口；`storage` 实现 SQLite 和加密文件；`security` 封装 AES-GCM 与 DPAPI；`preview` 定义共同正文模型；`mail` / `export` 实现输出；`application` 协调校验与发送；`ui` 处理视图和交互。

第一版使用 JavaFX 代码式视图与外部 CSS，未创建空的 FXML 文件。`MainController` 组合四个页面，复用 `Ui` 组件工具。后续可按页面拆分 Controller 或迁移到 FXML，不需要修改领域对象和输出服务。

题库校对和重建工具、原始截图及资源校对图位于随仓库提供的 `tools/exercise_bank/`；具体命令和依赖见 [题库重建与验证](exercise-bank.md#重建与验证)。运行时只读数据库，不含新增题库维护界面。启动时内置题库内容版本更新会先备份再替换运行时副本；相同版本、更高版本及自定义版本不覆盖。

## 本地存储

开发运行时数据写入项目 `data/`；JAR 运行时写在 JAR 所在目录；jpackage 发布版优先根据 `jpackage.app-path` 解析启动器目录。可通过绝对路径系统属性 `mailassistant.home` 显式指定应用根目录。不能写入时提示错误，不回退到用户目录。

```text
data/
  database/exercise.db
  config/user-profile.enc
  config/secrets/master-key.dpapi
  config/secrets/smtp-<账号摘要>.dpapi
  drafts/<UUID>/draft.enc
  export/
  cache/
  logs/
```

资料、邮箱非秘密配置和草稿使用 AES-256-GCM，独立随机 nonce；主密钥与授权码通过 Windows 当前用户 DPAPI 保护。图片字节直接包含在加密草稿中，磁盘没有额外明文截图副本。显式导出的 DOCX 是明文，由用户选择保存位置。

复制应用到另一 Windows 账户或机器后，旧 DPAPI 密钥不保证可解密；请保留原账户及完整数据目录。删除主密钥会使已有加密资料不可恢复。应用没有实现跨机器密钥恢复或自动备份。

「清除此账号凭据与个人设置」删除设置及当前账号凭据；其他账号凭据和草稿保留。草稿可能包含以前的身份信息。

## 邮箱认证与限制

QQ / 163 默认预设可在界面中修改。发件账号只需输入 @ 前的部分，程序按所选服务商补全后缀。只允许 SSL 或必须成功升级的 STARTTLS，并验证服务端证书主机名；设置连接/读取/写入超时。

OAuth2 当前接收用户已有访问 Token，使用 XOAUTH2；尚未实现浏览器授权、刷新 Token 流程。SMTP 授权码由用户在邮箱服务商处申请。真实服务器参数、认证与投递尚需使用自己的账号做集成验收；自动测试不发送真实邮件。网络异常后先核对已发送记录，再决定是否重试，避免重复提交。

程序不会执行用户导入的 Java 代码，不会生成作业答案，也不会自动发送邮件。

## 图标和托盘

见 [桌面集成](desktop-integration.md)。托盘菜单包含「主界面」「个人信息」「草稿箱」「退出」；双击恢复窗口，右上角关闭默认隐藏到托盘，可在个人中心改为直接退出。草稿箱支持命名、打开和确认删除，按保存时间保留最新 30 条草稿。托盘不可用时关闭窗口正常执行退出检查。
